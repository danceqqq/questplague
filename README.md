# Fork [Quest Plaques " by.Grend "](https://modrinth.com/mod/quest-plaques) to new version **Forge**

### Description
_This mod is an add-on for the Advancement Plaques mod, providing the same fancy popups for quest completion in various questing mods._

### Client / Server
This addon needs to be installed on both the **client and server** (as does Advancement Plaques).

### Compatibility

Currently supports quests from [FTB Quests](https://www.curseforge.com/minecraft/mc-mods/ftb-quests-forge) and [Custom Quests](https://www.curseforge.com/minecraft/mc-mods/customquests).  More quest mods may be added in the future, depending on demand.
